关于

本站只做了两件事：
1. 定时把公开 EPG 源聚合成一份静态 XMLTV（GitHub Actions，非本站实时抓取）；
2. 纯前端做直播源格式转换，你的源不会离开浏览器。

频道名经过 繁→简 / 去修饰词 / 字典匹配 三级标准化，再按省市区分组。
